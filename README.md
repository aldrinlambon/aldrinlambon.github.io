# aldrinlambon.github.io
Personal portfolio of Aldrin Lambon. Plain HTML, no build step.

## Deploy
1. Create a PUBLIC repo named exactly `aldrinlambon.github.io`.
2. Unzip on your computer, open the repo on GitHub > Add file > Upload files.
3. Drag ALL files (index.html, 404.html, robots.txt, sitemap.xml, README.md) to the repo root. Commit to `main`.
4. Settings > Pages > Source: Deploy from a branch > `main` / `(root)` > Save.
5. Live at https://aldrinlambon.github.io in 1-2 minutes.
